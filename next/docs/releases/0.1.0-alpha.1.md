# WePush Next 0.1.0-alpha.1 — Public Preview

这是 WePush Next 新架构产品线的首个公开预览版。Classic 客户端不受影响，仍在原有目录中独立演进。

## 下载内容

- `wepush-next-0.1.0-alpha.1.tar.gz` / `.zip`：Service、Agent、WebUI 和 Linux/macOS/Windows 服务安装脚本。
- `wepush-next-java-sdk-0.1.0-alpha.1.zip`：Java SDK、公开 API 契约和本地 Maven 安装说明。
- `wepush-next-desktop-0.1.0-alpha.1-<os>-<arch>.*`：对应平台的 Electron Desktop 应用。
- `wepush-next-0.1.0-alpha.1-sbom.cdx.json`：CycloneDX 软件物料清单。
- `SHA256SUMS`：全部发布附件的 SHA-256 校验值。

运行 Service、Agent 与 Java SDK 需要 Java 21。具体安装、配置、备份、升级和卸载步骤见分发包中的 `docs/deployment-and-operations.md`。

第一次使用请阅读[《WePush Next 对外使用指南》](https://github.com/rememberber/WePush/blob/master/next/docs/user-guide.md)，其中包含发行物选择、三平台便携启动与服务安装、Desktop 连接、首个安全 Dry Run、正式 API 调用和常见问题。

## 重要提示

这是未签名的预览发行：macOS 没有 Developer ID/Notarization，Windows 没有 Authenticode。操作系统可能显示未知开发者警告。请只从本 Release 下载并校验 `SHA256SUMS`；不要将本版本直接用于关键生产业务。

API、数据结构和升级路径仍可能变化。升级前请备份数据库、Secret 主密钥、Agent 身份、插件与 Artifact。完整边界见 `PREVIEW-NOTICE.md`，安全问题请按 `SECURITY.md` 私下报告。

## 主要能力

- Core Engine 与 Provider SPI；内置 HTTP Provider。
- 可独立安装的 Service 与 Agent，支持本机执行和远端 gRPC 执行。
- SQLite Standalone、PostgreSQL Server/HA 基线，以及 Local/S3 Artifact Store。
- Java SDK、OpenAPI、React WebUI、可视化配置和运行中心。
- Electron Desktop 外壳和 Linux、macOS、Windows 服务脚本。

详细变化见 `CHANGELOG.md`。
