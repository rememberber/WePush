# WePush Next 0.1.0-alpha.3 — Public Preview

`0.1.0-alpha.3` 完成日常使用闭环。用户现在可以在 WebUI 或 Desktop UI 中导入受众、配置资源、先做 Dry Run、核对正式发送影响、查看结果并只重发失败项；不需要手写 Recipient JSON 或直接调用 API。

WePush Next 仍只面向用户自行下载、安装、部署和运维。项目不提供官方公共 SaaS、注册、计费、订阅、公共租户平台、云 KMS/Secret Manager 集成或面向恶意公共租户的物理隔离。

## 主要变化

- Account 支持编辑、Provider 连接测试、启停和归档。
- Message 内容更新生成不可变 Revision，并支持历史、Diff 和复制；Audience 内容更新生成不可变 Snapshot。
- Audience 支持 CSV/TXT 流式导入、字段映射、最多 20 行预览、数据库去重、错误行 CSV 下载，以及新建或更新快照。
- Job 支持编辑、复制、启停和归档；Schedule 可编辑名称、Job、Cron、时区、Misfire 和启停状态。
- 正式发送前展示 Provider/版本、账号、受众、策略、并发、限速和预计规模，并要求使用短期确认令牌。
- 可筛选 FAILED、UNKNOWN、UNSENT Item 创建关联的新 Run；新 Run 复用来源 Run 的冻结 Snapshot，只执行选中 Item。
- Run、Account、Message、Audience、Job、Schedule 和审计统一使用签名 Cursor Page，并支持名称、状态和时间筛选。
- 总览接入真实 Run 总数、活动数、成功数、问题数、活动/最近 Run 和 14 天趋势。
- Standalone 隐藏 Workspace 复杂度；用户自建 Server 使用真实 Workspace 选择。
- OpenAPI、TypeScript Client 和 Remote Java SDK 已同步；Java SDK 的受众上传使用流式 multipart 文件 BodyPublisher。

## 验证

- 完整 Maven 测试矩阵通过，包括 OpenAPI、SQLite 13 个迁移、Service/API、Agent/gRPC、架构、SDK 和 HTTP Provider 纵向测试。
- 集成测试覆盖 CSV 导入/去重/错误下载、不可变 Snapshot、正式发送确认、真实 HTTP 部分失败和筛选重发。
- pnpm TypeScript、Vitest、Web Vite 和 Desktop 构建通过。
- PostgreSQL 与 S3-compatible 集成仍由带对应服务的 CI 门禁验证。
