# WePush Next 0.1.0-alpha.2 — Public Preview

`0.1.0-alpha.2` 是一次产品方向和安全收口发布。WePush Next 的长期目标已明确为开源、可下载、可安装、由用户自行部署和运维；项目不建设官方公共 SaaS、注册计费订阅、公共租户平台或云 KMS/Secret Manager 集成。Classic 客户端不受影响，继续在原有目录中独立演进。

## 主要变化

- 新增产品目标、永久边界和 `alpha.2` 至 `1.0.0` 的分版本路线图，并同步 README、架构、详细设计、ADR、部署和实现状态文档。
- 新增 Embedded Java SDK，Java 应用可在自身 JVM 中显式装配 Core Engine 和允许的 Provider，无需启动 Service、Agent 或数据库。
- 发行包和独立 Java SDK 附件同时携带 Remote SDK、Embedded SDK、Core API、Provider SPI、Engine 和 HTTP Provider 的 POM/JAR。
- 修复开启 API Security 时 WebUI Artifact 下载没有携带 Bearer Token 的问题。
- S3-compatible Artifact Store 只保留 `AUTO`/`AES256`/`NONE` 服务端加密配置，移除 AWS KMS 配置与实现路径。
- 修正 macOS Desktop 主可执文件和应用版本元数据，三平台发布工作流会校验包内产品版本。

完整产品边界与后续计划见[《产品目标、边界与路线图》](../product-scope-and-roadmap.md)。

## 下载内容

- `wepush-next-0.1.0-alpha.2.tar.gz` / `.zip`：Service、Agent、WebUI、OpenAPI、Java SDK 和 Linux/macOS/Windows 服务安装脚本。
- `wepush-next-java-sdk-0.1.0-alpha.2.zip`：Remote/Embedded Java SDK 与它们的本地 Maven 安装依赖。
- `wepush-next-desktop-0.1.0-alpha.2-<os>-<arch>.*`：Linux x64、macOS Apple Silicon 和 Windows x64 Desktop 应用。
- `wepush-next-0.1.0-alpha.2-sbom.cdx.json`：CycloneDX 软件物料清单。
- `SHA256SUMS`：全部发布附件的 SHA-256 校验值。

运行 Service、Agent 或 Java SDK 需要 Java 21 或更高版本。安装、便携启动、备份、升级和卸载步骤见[《对外使用指南》](../user-guide.md)和[《部署与运维》](../deployment-and-operations.md)。

## 预览版提示

本版本仍不是稳定版，API、配置、数据结构和升级路径可能变化，不建议直接用于关键生产业务。Desktop 和安装包未使用商业代码签名：macOS 没有 Developer ID/Notarization，Windows 没有 Authenticode。请只从本 Release 下载并校验 `SHA256SUMS`。

升级前请备份数据库、Secret 主密钥、Agent 身份、插件与 Artifact。安全问题请按 `SECURITY.md` 私下报告。
